## 📅 5-Day Learning Path

### **Day 1: Array Fundamentals & Basics**
*Focus: Understanding array operations, searching, and basic manipulations*

#### Learning Objectives:
- ✅ Array declaration and initialization
- ✅ Array indexing and iteration
- ✅ Basic search operations (Linear, Binary)
- ✅ Array manipulation basics

#### Problems to Solve:

1. ✅ **Linear Search in Array**
   - Input: Array of integers, target value
   - Output: Index of target or -1 if not found
   - Complexity: O(n) time, O(1) space
   - Concepts: Basic iteration, conditionals

2. ✅ **Binary Search**
   - Input: Sorted array, target value
   - Output: Index of target or -1 if not found
   - Complexity: O(log n) time, O(1) space
   - Concepts: Divide and conquer, pointers

3. ✅ **Find the Maximum Element**
   - Input: Array of integers
   - Output: Maximum value
   - Complexity: O(n) time, O(1) space
   - Concepts: Single pass iteration

4. ✅ **Find Duplicate Elements**
   - Input: Array with duplicates
   - Output: All duplicate values
   - Complexity: O(n) time, O(n) space
   - Concepts: Hash set/map

5. ✅ **Remove Duplicates from Sorted Array**
   - Input: Sorted array with duplicates
   - Output: Array with duplicates removed, return length
   - Complexity: O(n) time, O(1) space
   - Concepts: Two-pointer technique

---

### **Day 2: Array Manipulation & Two-Pointer Technique**
*Focus: Modifying arrays, rearranging elements, two-pointer patterns*

#### Learning Objectives:
- ✅ Two-pointer technique
- ✅ Array rearrangement
- ✅ Sorting fundamentals
- ✅ Partitioning arrays

#### Problems to Solve:

1. ✅ **Reverse an Array**
   - Input: Array of integers
   - Output: Reversed array
   - Complexity: O(n) time, O(1) space
   - Concepts: Two pointers, in-place reversal

2. ✅ **Move All Zeros to End**
   - Input: Array of integers
   - Output: Array with all zeros moved to end
   - Complexity: O(n) time, O(1) space
   - Concepts: Two-pointer, element shifting

3. ✅ **Rotate Array by K positions**
   - Input: Array and rotation count K
   - Output: Rotated array
   - Complexity: O(n) time, O(1) space (optimal)
   - Concepts: Array rotation algorithms

4. ✅ **Sort Array of 0s, 1s, and 2s (Dutch National Flag)**
   - Input: Array containing 0s, 1s, 2s
   - Output: Sorted array
   - Complexity: O(n) time, O(1) space
   - Concepts: Three-pointer technique

5. ✅ **Merge Two Sorted Arrays**
   - Input: Two sorted arrays
   - Output: One merged sorted array
   - Complexity: O(m+n) time, O(m+n) space
   - Concepts: Merge algorithm, two pointers

---

### **Day 3: String Fundamentals & Manipulation**
*Focus: String operations, pattern matching, and transformations*

#### Learning Objectives:
- ✅ String basics and immutability
- ✅ String searching and pattern matching
- ✅ String manipulation techniques
- ✅ Character analysis

#### Problems to Solve:

1. **Reverse a String**
   - Input: String
   - Output: Reversed string
   - Complexity: O(n) time, O(1) space (excluding output)
   - Concepts: String reversal, character swapping

2. **Check if String is Palindrome**
   - Input: String
   - Output: Boolean (true/false)
   - Complexity: O(n) time, O(1) space
   - Concepts: Two-pointer, character comparison

3. **Find Duplicate Characters**
   - Input: String
   - Output: Characters that appear more than once
   - Complexity: O(n) time, O(k) space (k = unique chars)
   - Concepts: Hash map, frequency counting

4. **Remove Duplicate Characters**
   - Input: String with duplicates
   - Output: String with duplicates removed (preserve first occurrence)
   - Complexity: O(n) time, O(k) space
   - Concepts: Hash set, order preservation

5. **First Unique Character in String**
   - Input: String
   - Output: Index of first character that appears only once, or -1
   - Complexity: O(n) time, O(k) space
   - Concepts: Frequency counting, hash map

---

### **Day 4: Advanced String Algorithms & Patterns**
*Focus: Complex string operations, subsequences, and pattern recognition*

#### Learning Objectives:
- ✅ Pattern matching algorithms
- ✅ Substring operations
- ✅ String compression and encoding
- ✅ Advanced string manipulation

#### Problems to Solve:

1. **Longest Substring Without Repeating Characters**
   - Input: String
   - Output: Length of longest substring without repeating chars
   - Complexity: O(n) time, O(min(m,n)) space
   - Concepts: Sliding window, hash map

2. **Longest Common Prefix**
   - Input: Array of strings
   - Output: Longest common prefix string
   - Complexity: O(m*n) time (m = number of strings, n = average length)
   - Concepts: String comparison, prefix finding

3. **Check if String is Anagram**
   - Input: Two strings
   - Output: Boolean
   - Complexity: O(n) time, O(1) space (fixed alphabet)
   - Concepts: Character frequency, sorting

4. **Group Anagrams**
   - Input: Array of strings
   - Output: Grouped anagrams
   - Complexity: O(n*k*log k) time (k = average string length)
   - Concepts: Hash map, sorting, grouping

5. **Compress String**
   - Input: String (e.g., "aaabcccccc")
   - Output: Compressed string (e.g., "a3b1c5")
   - Complexity: O(n) time, O(n) space
   - Concepts: Character counting, string building

---

### **Day 5: Combined Array & String Problems + Practice**
*Focus: Integration of concepts, real-world scenarios, and comprehensive practice*

#### Learning Objectives:
- ✅ Combining array and string techniques
- ✅ Problem-solving optimization
- ✅ Edge case handling
- ✅ Code review and refinement

#### Problems to Solve:

1. **Word Search in Matrix**
   - Input: 2D array (matrix) of characters, word to search
   - Output: Boolean (found/not found)
   - Complexity: O(m*n*l) time (m,n = matrix dimensions, l = word length)
   - Concepts: 2D array traversal, DFS/BFS, backtracking

2. **Rotate String**
   - Input: String and rotation amount K
   - Output: Rotated string
   - Complexity: O(n) time, O(n) space
   - Concepts: String manipulation, modulo operations

3. **Majority Element in Array**
   - Input: Array of integers
   - Output: Element appearing more than n/2 times (if exists)
   - Complexity: O(n) time, O(1) space (Boyer-Moore voting)
   - Concepts: Voting algorithm, element counting

4. **Two Sum Problem**
   - Input: Array of integers, target sum
   - Output: Indices of two numbers that add up to target
   - Complexity: O(n) time, O(n) space (hash map)
   - Concepts: Hash map, two-sum pattern

5. **Longest Palindromic Substring**
   - Input: String
   - Output: Longest substring that is palindrome
   - Complexity: O(n²) time, O(1) space (expand around center)
   - Concepts: Palindrome detection, string expansion

6. **Word Break Problem**
   - Input: String and dictionary
   - Output: Boolean (can be segmented into dictionary words)
   - Complexity: O(n²) time, O(n) space
   - Concepts: Dynamic programming, word matching

7. **Practice: Mixed Array-String Problem**
   - Input: Character array representing sentence
   - Output: Reverse only the words, keep spaces in place
   - Complexity: O(n) time, O(1) space
   - Concepts: Array manipulation, character handling

## 📚 Key Concepts Reference

### Arrays
- **Linear Search**: O(n) - useful for unsorted data
- **Binary Search**: O(log n) - requires sorted data
- **Two-Pointer Technique**: Efficient for arrays with two movable pointers
- **Sorting**: Fundamental for optimization
- **Space Optimization**: In-place algorithms preferred

### Strings
- **Immutability**: Strings are immutable in most languages
- **Hash Map/Set**: Efficient character frequency tracking
- **Sliding Window**: Useful for substring problems
- **Two-Pointer**: Effective for palindrome and reversal
- **Pattern Matching**: Essential for substring search
